# risk-management-hw1
# Практична робота № 2. Ризик-орієнтоване управління фінансовими установами: VaR та Expected Shortfall

## 1. Мета роботи

Метою практичної роботи є оцінювання фінансового ринкового ризику за допомогою показників Value at Risk (VaR) та Expected Shortfall (ES), а також порівняння результатів, отриманих різними методами розрахунку.

## 2. Об'єкти дослідження та вихідні дані

Для аналізу використано дані про скориговані ціни закриття двох фінансових активів:

- **Apple Inc. (AAPL)** - акції окремої компанії.
- **S&P 500 (^GSPC)** - фондовий індекс, що характеризує динаміку широкого сегмента американського фондового ринку.

**Період дослідження:** з 13.10.2023 до 12.10.2026.

**Кількість спостережень щоденної дохідності:** 749.

Дані завантажуються з Yahoo Finance за допомогою пакета `quantmod` у середовищі R.

## 3. Методика дослідження

На основі скоригованих цін закриття розраховано щоденну логарифмічну дохідність фінансових активів.

Для оцінювання ризику використано такі показники:

- історичний VaR на рівнях довіри 95% та 99%;
- параметричний VaR на рівнях довіри 95% та 99%;
- історичний Expected Shortfall на рівні довіри 95%.

Історичний метод ґрунтується на фактичному розподілі дохідності за досліджуваний період. Параметричний метод передбачає нормальний розподіл дохідності. Expected Shortfall характеризує середній розмір втрат у найгірших 5% спостережень.

Розрахунки виконано мовою R із використанням пакетів `quantmod`, `PerformanceAnalytics`, `ggplot2` та `xts`.

## 4. Результати розрахунків

У таблиці наведено оцінки потенційних втрат за один торговий день. Значення показників подано у відсотках.

| Показник ризику | Apple (AAPL), % | S&P 500, % |
|---|---:|---:|
| Історичний VaR 95% | 2,548 | 1,468 |
| Історичний VaR 99% | 4,646 | 2,538 |
| Параметричний VaR 95% | 2,684 | 1,470 |
| Параметричний VaR 99% | 3,831 | 2,112 |
| Історичний ES 95% | 3,910 | 2,143 |

## 5. Аналіз отриманих результатів

Результати розрахунків показують, що протягом досліджуваного періоду акції Apple мали вищі оцінені показники щоденного ризику, ніж індекс S&P 500.

За історичним методом VaR на рівні 95% становить 2,548% для Apple та 1,468% для S&P 500. Це означає, що за умов застосованого методу відповідний поріг втрат не перевищувався приблизно у 95% спостережень. На рівні 99% показники становлять відповідно 4,646% та 2,538%.

За параметричним методом VaR на рівні 95% дорівнює 2,684% для Apple та 1,470% для S&P 500. На рівні 99% значення становлять 3,831% та 2,112% відповідно. Відмінності між історичним і параметричним методами пояснюються різними підходами до оцінювання розподілу дохідності.

Історичний Expected Shortfall на рівні 95% становить 3,910% для Apple та 2,143% для S&P 500. Цей показник характеризує середні втрати в найгірших 5% спостережень і допомагає оцінити можливий масштаб збитків за межами порога VaR.

Отже, за обраний період акції Apple характеризувалися вищим оціненим ризиком щоденних втрат порівняно з індексом S&P 500. Водночас результати базуються на історичних даних і не гарантують аналогічної поведінки активів у майбутньому.

## 6. Структура репозиторію

У репозиторії розміщено такі файли:

- `scripts/main_analysis.R` - R-скрипт для завантаження даних, розрахунку показників ризику та побудови графіка.
- `data/adjusted_prices.csv` - дані про скориговані ціни закриття активів.
- `data/log_returns.csv` - розраховані щоденні логарифмічні дохідності.
- `data/risk_metrics.csv` - результати розрахунків VaR та ES.
- `data/var_chart.png` - гістограми розподілу щоденної дохідності з позначеними порогами історичного VaR.

## 7. Висновок

У ході практичної роботи було проаналізовано щоденну дохідність акцій Apple та фондового індексу S&P 500 за трирічний період. За допомогою історичного та параметричного методів розраховано VaR на рівнях довіри 95% і 99%, а також історичний Expected Shortfall на рівні 95%.

Розрахунки показали, що акції Apple мали вищі оцінені показники ризику, ніж S&P 500. Використання VaR та ES дає змогу кількісно оцінювати потенційні втрати та порівнювати ризиковість різних фінансових активів.
